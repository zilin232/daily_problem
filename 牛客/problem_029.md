- # **题目描述：**

上体育课了！今天的项目是折返跑，笔直的跑道可以看作是一条数轴。跑道上有 n 个点位，其中，老师在 1 点和 n 点处各放了两根杆子，称为左杆和右杆，作为折返跑的折返点。

老师规定，今天一共需要跑 m 趟。我们认为，从一根杆子开始，跑到另一根杆子结束为一趟，显然，一共需要进行 \(m-1\) 次折返。Zaoly 偶然发现，杆子是可推动的，所以他有了一个大胆的想法 ——

- 每次跑至右杆折返后，都需要把右杆向左推动一段距离（大于 0），但仍保证右杆位于整数点，且在左杆的右边（不能与左杆重合）；
- 每次跑至左杆折返后，都需要把左杆向右推动一段距离（大于 0），但仍保证左杆位于整数点，且在右杆的左边（不能与右杆重合）；

现在，给出整数 n 和 m 的值，请问 Zaoly 一共有多少种不同的推杆方法？由于答案可能很大，请将答案对 \((10^9 + 7)\) 取模后输出。注意，每次折返时都需要推杆，如果某一轮无法推动，则这一轮推杆非法。

## 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 \(T\ (1 \le T \le 10^4)\) 代表数据组数，每组测试数据描述如下： 对于每一组测试数据，输入两个整数 \(n,m\ (1 \le m < n \le 10^6)\) 代表点位的数量、折返跑的趟数。

## 输出描述

对于每组数据，在一行上输出一个整数代表合法的推杆方法种数。由于答案可能很大，请将答案对 \((10^9 + 7)\) 取模后输出。

- # **题目题解：**

观察发现答案是 \(\mathrm{C}_{n-2}^{m-1}\)​

这是大佬的推导（牛客的   白藜喵   ）

首先推杆的次数是固定的，是 \(m-1\)。推杆的总距离是变的，最小距离是 \(m-1\)，也就是每次移动一格；最大距离是 \(n-2\)，也就是推到两个杆相邻。先分析推杆的总距离为 k 的情况。

现在把推杆的次数看作盒子，推一格的操作看作小球，就把这道题转化为计数题：k 个相同的小球放入 \(m-1\) 个不同的盒子，要求每个盒子至少放一个小球，有几种放法。

先取出 \(m-1\) 个小球分配到所有盒子，那么剩下 \(k-(m-1)\) 个小球就可以自由支配。剩下的小球有 \(\mathrm{C}_{k-1}^{k-m+1}\) 种放法，因为 m 个相同的小球放入 n 个不同的盒子，每个盒子可以放多个，方案数有 \(\mathrm{C}_{n+m-1}^{m}\)，这是结论，记住即可。

然后把 k 的所有取值的方案数加起来就是答案，即 \(\displaystyle\sum_{k=m-1}^{n-2}\mathrm{C}_{k-1}^{k-m+1}\)。

但是还没完，题目并没有限制全部数据的 n 之和，这意味着你需要把求和式子化简，否则会超时。把下标平移，变成 \(\displaystyle\sum_{k=0}^{n-m-1}\mathrm{C}_{k+m-2}^{k}\)，然后开始化简。

知道一个公式：\(\mathrm{C}_{n-1}^{m-1}+\mathrm{C}_{n-1}^{m}=\mathrm{C}_{n}^{m}\)，想想杨辉三角怎么递推就知道这个公式怎么来。然后看这个求和：\(\mathrm{C}_{m-2}^{0}+\mathrm{C}_{m-1}^{1}+\mathrm{C}_{m}^{2}+\dots+\mathrm{C}_{n-3}^{n-m-1}\)。

可以把首项 \(\mathrm{C}_{m-2}^{0}\) 改为 \(\mathrm{C}_{m-1}^{0}\)，它们都等于 1，然后前两项就变成了 \(\mathrm{C}_{m}^{1}\)，这个再和第三项结合变成 \(\mathrm{C}_{m+1}^{2}\)…… 这种连锁反应可以把整个求和变成 \(\mathrm{C}_{n-2}^{m-1}\)。

 ```cpp
 #include<bits/stdc++.h>
 using namespace std;
 using ll=long long;
 using ull=unsigned long long;
 using ill=__int128;
 const ll mod1=1e9+7;
 const ll mod2=998244353;
 ll zh[1000020],ni[1000020];
 ll ksm(ll a,ll b){
     ll ans=1;
     while(b){
         if(b&1){
             ans=(ans*a)%mod1;
         }
         a=(a*a)%mod1;
         b=b/2;
     }
     return ans;
 }
 int main(){
     ios::sync_with_stdio(false);
     cin.tie(0);cout.tie(0);
     zh[0]=1;ni[0]=1;
     for(ll i=1;i<=1000000;i++){
         zh[i]=(zh[i-1]*i)%mod1;
     }
     ni[1000000]=ksm(zh[1000000],mod1-2);
     for(ll i=999999;i>=1;i--)ni[i]=(ni[i+1]*(i+1))%mod1;
     ll t;cin>>t;
     while(t--){
         ll n,m;cin>>n>>m;
         m--;n-=2;
         if(m==0)cout<<1<<'\n';
         else cout<<((((zh[n]*ni[m])%mod1+mod1)%mod1*ni[n-m])%mod1+mod1)%mod1<<'\n';
     }
     return 0;
 }
 ```
