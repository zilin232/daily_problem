- # **题目描述：**

“开导！”

众所周知，树是一种特殊的图。

众所周知（二），导出子图是由该图顶点的一个子集和该图中两端均在该子集的所有边的集合组成的图。

注 1：二叉树是有向图。

注 2：有向图的导出子图，还是有向图。

小沙有 n 个节点，他需要你构造出一颗有根二叉树，使得二叉树的所有导出子图是一颗满二叉树的数目尽可能多。

请问构造出来的有根二叉树的所有导出子图是一颗满二叉树的数目最多是多少？

你能帮帮不会数 / 树的小沙吗？

## 输入描述：

第一行读入一个整数 T，代表多组样例。

随后 T 行，每行输入一个正整数 n。

保证有 \(1 \le T \le 10^5,\ 1 \le n \le 10^{18}\)。

## 输出描述：

对于每组样例输出一行整数代表答案。

由于答案过大，所以请输出答案对 \(10^9 + 7\) 取模的值。

- # **题目题解：**

 ```cpp
 //解法一：
 #include<bits/stdc++.h>
 using namespace std;
 using ll=long long;
 using ull=unsigned long long;
 using ill=__int128;
 const ll mod1=1e9+7;
 const ll mod2=998244353;
 int main(){
     ios::sync_with_stdio(false);
     cin.tie(0);cout.tie(0);
     ll a[62]={0};a[1]=1;//i层满二叉树的子图为满二叉树的数量
     for(ll i=2;i<=61;i++){
         ll p=((ll)1)<<(i-1);
         p=p%mod1;
         a[i]=(a[i-1]+p*2-1)%mod1;
     }//每多加一层，该层节点与之前的节点的每一个节点都可以作为根构建一个满二叉树
     int t;cin>>t;
     while(t--){
         ll n;cin>>n;
         ll m=n;
         ll p=1;
         ll an=0;
         while(p<=n){
             p=p*2+1;
             an++;
             if((p)>n)break;
         }//计算能放满几层
         ll ans=a[an]%mod1;
         n=n-((p-1)/2);
         for(ll i=1;i<=an;i++){
             if(n&1){
                 ans=(ans+(((ll)1)<<i)%mod1-1)%mod1;
             }
             n=n/2;
         }
         //将剩余节点分成多个二的某次幂相加
         //对于每一个2的某次幂（记作2的i次幂）都可以看作往一个i层高的满二叉树新加一层。
         cout<<(ans+mod1)%mod1<<'\n';
     }
     return 0;
 }
 ```

//严谨证明（copy的大佬的）（牛客的 牛客203596504号 ）

这道题有点复杂，而且要**严谨证明**就更复杂，下面我试着给出证明。
证明要分两步：先计算理论上限，然后证明这个上限能够构造出来。
特别强调：如果有人直接给出构造方案，然后基于方案计算，那他的证明是**不严谨**的！

我们按照树高把导出子图分为树高为1到树高为i的满二叉树，各自计数。
我们要在不假设原树结构的情况下，证明三个结论：

1. 任意两棵高度相同的满二叉树，叶子节点不可以有交集。

反证法：如果某节点在两棵高度相同的满二叉树中都是叶子节点，那么这两棵满二叉树的根节点都是这个节点向上i层祖先，是同一个点。然而，以同一个节点为根，而高度也相同的满二叉树，只能有一棵，引出矛盾命题得证。

2. 对于任何一棵树，非叶子节点必然不是叶子节点。

这是“非叶子节点”的定义，无需证明，但列出来是为了证明完备。

3. 对于原图中根节点最高的那棵(或多棵)导出子图满二叉树，它的所有非叶子节点不可以充当相同高度的其他满二叉树的叶子节点。

反正法：满二叉树的叶子节点高度等于树高，非叶子节点高度小于树高，如果它的非叶子节点是另一棵满二叉树的叶子节点，由节点位置减去相对根节点的高度，可以得到，那棵满二叉树的根节点比它更高，引出矛盾命题得证。
根据这三个结论，对于高度为 i+1 的导出子图满二叉树：
有不少于2i-1个节点(根节点最高的那棵)不能充当任何满二叉树的叶子节点。
每棵满二叉树要独占2i个叶子节点，不能与其他满二叉树共用。

根据抽屉原理，上限就是![img](https://hr.nowcoder.com/equation?tex=%5Csum_%7Bi%3D0%7D%5E%7B%5Cinfty%7D%7B%5Clfloor%5Cfrac%7Bn-(2%5Ei-1)%7D%7B2%5Ei%7D%5Crfloor%7D)

理论上限是求出来了，但我们还要证明这个上限确实能构造出来。
构造方案就是“节点数为n的完全二叉树”，我们数一下数量：
从第0层(节点编号>0)起，每增加1个节点就增加1个高度为1的满二叉树。
从第1层(节点编号>1)起，每增加2个节点就增加1个高度为2的满二叉树。
从第2层(节点编号>3)起，每增加4个节点就增加1个高度为4的满二叉树。
从第i层(节点编号>2i-1)起，每增加2i个节点就增加1个高度为2i的满二叉树。

累加结果恰好是![img](https://hr.nowcoder.com/equation?tex=%5Csum_%7Bi%3D0%7D%5E%7B%5Cinfty%7D%7B%5Clfloor%5Cfrac%7Bn-(2%5Ei-1)%7D%7B2%5Ei%7D%5Crfloor%7D)

至此，我们计算了理论上限，并且证明了理论上限确实能够构造出来。
